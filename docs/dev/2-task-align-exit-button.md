## 1. 目标

- 要解决的问题：调整按钮行布局，使“继续启动”保持现有位置，“退出”右对齐。
- 成功标准：“继续启动”按钮坐标不变；“退出”按钮右边缘与表单/输入框右边缘对齐；程序可构建。

## 2. 背景与边界

- 背景：当前两个按钮使用固定间距并整体居中。
- 包含：调整 `src/main.c` 中按钮布局变量和绘制坐标。
- 不包含：修改焦点顺序、按钮尺寸、认证流程、整体页面结构。
- 关键假设：右对齐指与当前表单区域右边缘对齐，而不是贴到屏幕外框。
- 非目标：不改变其它控件布局。
- 最大修改范围：`src/main.c`、`docs/dev/`。
- 禁止触碰范围：不修改 `/data/source/kmscube`；不触碰未跟踪 `.codex`。

## 4. 方案

- 推荐方案：保留原 `buttons_x` 作为“继续启动”的 x 坐标，新增 `exit_button_x = form_x + form_w - button_w`，让“退出”按钮右边缘对齐表单右边缘。
- 取舍理由：最小改动，避免影响其它控件与交互逻辑。
- 风险与应对：仅通过构建验证和补丁检查确认无编译/格式问题；视觉位置需目标环境实机确认。
